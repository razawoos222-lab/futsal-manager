JMFC 경기 기록 조작 설명서

  1. 처음부터 결과 저장까지 · 팀원 공유용
  2. 목업 링크에서 그대로 눌러보며 연습하세요
  3. htmlpreview.github.io 링크로 열면 설치 없이 실행됩니다
STEP 1

1. 참석 조사

  1. 날짜를 확인합니다
  2. 2팀 / 3팀 / 4팀 중 오늘 구성을 고릅니다
  3. 참석 선수 칩을 탭해 선택합니다
  4. 「참석 완료 →」로 다음
STEP 2

1-2. 참석자 선택 팁

  1. 지난경기 참석자 · 전체선택 · 전체해제를 쓸 수 있습니다
  2. 선택 인원이 팀 수 이상이어야 다음으로 갑니다
  3. 용병은 이름 옆에 용병 표시가 있습니다
STEP 3

2. 감독 선택

  1. 팀 슬롯(RED/BLUE/YELLOW…)을 탭합니다
  2. 아래 선수 칩을 눌러 그 팀 감독을 지정합니다
  3. 모든 팀 감독을 채운 뒤 「다음 →」
  4. 감독은 드래프트·결과에서 C 표시로 유지됩니다
STEP 4

3. 세션 핀번호

  1. 첫 드래프트 입장 때 4자리 핀을 정합니다
  2. 드래프트 재입장·확정·라인업 삭제에 사용합니다
  3. 세션을 리셋하기 전까지 유지됩니다
  4. 팀원과 공유할 핀은 구두로 전달하세요
STEP 5

4. 드래프트

  1. 스네이크 ON이면 픽 순서대로 팀이 자동 전환됩니다
  2. 선수 카드를 탭해 배정 · 다시 탭하면 취소
  3. 랜덤 배정 / 배정 초기화도 가능합니다
  4. 팀 카드에서 드래그로 팀 이동 가능
  5. 전원 배정 후 「드래프트 완료」→ 핀 확인
STEP 6

5. 라인업 확정

  1. 드래프트 확정 후 팀별 명단이 랜덤 순서로 보입니다
  2. 감독(C)은 맨 앞에 고정됩니다
  3. 「라인업 공유」로 이미지를 저장·카톡 전송할 수 있습니다
  4. 확인 후 경기선택으로 이동합니다
STEP 7

6. 경기 선택

  1. 오늘 붙일 2팀을 고릅니다 (예: RED vs BLUE)
  2. 경기 시간 7~12분을 설정합니다
  3. 「경기시작」으로 라이브 기록 화면 진입
  4. 지난 경기를 탭하면 수정 모드로 다시 열 수 있습니다
STEP 8

7. 경기 기록 · 라인업

  1. 「경기시작」으로 타이머를 돌립니다
  2. 선수 이름을 탭 → 득점/도움/수비/선방/자책 기록
  3. ⇄ 버튼으로 교체·코트 아웃 메뉴
  4. 현재 경기 종료 / 전체 세션 종료로 다음 단계
STEP 9

7-2. 스탯 입력 팝업

  1. 선수 선택 후 원하는 스탯 버튼을 누릅니다
  2. 득점이면 이어서 도움 선수를 고를 수 있습니다
  3. 「스탯취소」로 마지막 기록을 되돌립니다
  4. 자책골은 상대 팀에 점수가 올라갑니다
STEP 10

7-3. 팀순위 · 개인기록 탭

  1. 팀순위 탭에서 승점·득실을 확인합니다
  2. 개인기록 탭에서 선수별 누적 스탯을 봅니다
  3. 타임라인을 펼치면 골 시각·도움 목록이 보입니다
STEP 11

8. 오늘의 결과

  1. 공격/수비 MVP · 최우수 감독이 자동 집계됩니다
  2. 팀 순위와 팀별 선수 스탯(MP)을 확인합니다
  3. 「결과 공유」로 이미지 1장 저장 → 카톡 전송
  4. 「기록 수정」에서 숫자만 고칠 수 있습니다
STEP 12

9. 기록 수정

  1. 득점·도움·수비·선방 숫자를 직접 고칩니다
  2. MP는 입력 즉시 다시 계산됩니다
  3. 감독(C)은 수정해도 빠지지 않습니다
  4. 「수정 완료 → 결과로」를 누르면 저장됩니다
STEP 13

10. 메뉴 · 저장 · 리셋

  1. 우측 상단 ≡ 메뉴로 화면을 바로 이동할 수 있습니다
  2. 결과 화면 「기록 저장」→ 시트/로컬 보관
  3. 「기록 리셋」은 새 세션 · 핀을 다시 설정합니다
  4. 실전 GAS 배포본은 시트에 자동 반영됩니다

빠른 체크리스트

  1. ① 참석 → ② 감독 → ③ 핀 → ④ 드래프트 → ⑤ 라인업
  2. ⑥ 2팀 선택 → ⑦ 경기 기록 → ⑧ 경기 종료
  3. ⑨ 결과 확인·공유 → ⑩ 필요 시 기록 수정 → 저장
