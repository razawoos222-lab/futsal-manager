경기 기록 방법 가이드 · 휴대폰에서 한 명이 기록하는 기준

1 참석 2 감독 3 드래프트 4 라인업 5 경기선택 6 경기 7 결과·저장
시작 전 · Safari 또는 Chrome으로 웹앱을 엽니다. 카카오톡 인앱 브라우저는 저장이 끊길 수 있으니, 링크를 외부 브라우저로 여는 것을 권장합니다.

1. 참석 조사

  1. 상단에서 팀 수를 고릅니다. (2팀 / 3팀 / 4팀)
  2. 오늘 온 선수를 탭해서 참석 처리합니다.
  3. 지난번에 온 명단을 쓰려면 지난경기 참석자를 누릅니다.
  4. 인원이 맞으면 참석 완료 →
날짜는 화면의 경기 날짜를 기준으로 시트에 저장됩니다.

2. 감독 선택

  1. 팀 슬롯(RED / BLUE / YELLOW / BLACK)을 탭합니다.
  2. 그 팀 감독이 될 선수를 고릅니다. (참석자만 선택 가능)
  3. 팀 수만큼 감독을 다 채운 뒤 다음 →

3. 드래프트 (팀 나누기)

  1. 감독이 참석자를 자기 팀으로 가져갑니다.
  2. 빠르게 나누려면 랜덤 배정을 쓸 수 있습니다. (감독은 고정)
  3. 잘못 넣었으면 선수를 다른 팀으로 옮기거나, 추가/삭제로 고칩니다.
  4. 구성이 끝나면 다음 → (라인업 확인)

4. 라인업 확인

팀별 명단을 한번 더 확인한 뒤 다음 → 로 경기 선택으로 갑니다.

5. 경기 선택 · 시작

  1. 맞붙을 2팀을 고릅니다.
  2. 경기 시간(7~12분)을 선택합니다.
  3. 경기시작을 누릅니다.
  4. 중간에 나갔다가 돌아오면 진행 중 경기 재개로 이어서 기록할 수 있습니다.

6. 경기 중 기록 (가장 중요)

기본

  1. 라인업에서 선수 이름을 탭합니다.
  2. 기록 종류를 고릅니다.
버튼의미다음에 할 일
득점골 +1, 스코어 반영도움 준 선수 선택 (없으면 「없음」)
수비수비 +1—
선방선방 +1—
자책골상대 팀 스코어 +1—
  • 잘못 눌렀으면 이전 스탯 취소
  • 아래 타임라인에서 방금 기록이 쌓이는지 확인합니다.

교체 · 인원 조절

  • 선수교체 — 나가는 선수 → 들어오는 선수
  • 선수제거 — 코트에서 내림
  • 선수추가 — 대기팀/명단에서 투입

화면 탭

  • 라인업 — 실시간 기록
  • 순위 — 오늘 팀 승점 현황
  • 개인 — 팀별 득/도/수/선/MP

경기 / 세션 종료

  • 현재 경기 종료 — 이 매치만 끝내고 다시 경기 선택으로 (다음 매치 진행)
  • 전체 세션 종료 — 오늘 일정 끝내고 결과 화면으로

7. 결과 · 시트 저장

  1. 결과 화면에서 MVP·팀 순위·개인 스탯을 확인합니다.
  2. 숫자가 틀리면 기록 수정에서 고칩니다.
  3. 반드시 기록 저장 & NEW 세션을 눌러 시트에 남깁니다.
저장되면 스프레드시트에 반영됩니다.
· 기록실_개인기록 · 기록실_감독기록 / 감독기록 · 지난_팀_구성 · 세션 아카이브
주의
· 저장 전에 앱을 닫거나 새로고침하면 오늘 기록이 날아갈 수 있습니다.
· 「기록 리셋 & NEW」는 저장하지 않고 새 세션을 시작합니다.
· 저장 중 「연결 끊김(HTTP 0)」이 뜨면 카카오톡이 아닌 Safari/Chrome으로 다시 열어 저장하세요.

빠른 체크리스트 (매 세션)

  1. □ 참석·팀수 확인
  2. □ 감독 전원 지정
  3. □ 드래프트/라인업 확인
  4. □ 매치마다 2팀 선택 → 기록 → 경기 종료
  5. □ 세션 종료 후 기록 저장 & NEW
