휴대폰 GAS 배포

index.html은 매 접속 시 GitHub에서 자동 로드됩니다. Code.gs도 29,000자 붙여넣기 없이, 실행 메뉴에서 동기화 한 번으로 GitHub 내용을 끌어올 수 있습니다.

방금 “Code.gs 전체 복사”를 눌렀다면
굳이 그 긴 텍스트를 붙여넣지 마세요. 아래 짧은 패치만 넣고 → syncCodeGsFromGithub를 실행하면 Code.gs가 GitHub 최신으로 덮어씌워집니다.

자동 업데이트 구조

  • 화면(UI) — 웹앱 열 때마다 GitHub live/index.html 로드 → 새로고침만으로 반영
  • 서버(Code.gs) — 폰에서 syncCodeGsFromGithub 실행 → GitHub 내용으로 교체 → 배포 → 새 버전 한 번

최초 1회 (짧은 패치)

1
Apps Script 사용자 설정에서 Google Apps Script API = ON
2
짧은 패치 복사 → script.google.com JMFC 프로젝트 Code.gs 맨 아래에 붙여넣기 · 저장
3
실행: useGithubRefPrBranch → 권한 허용
4
실행: syncCodeGsFromGithub (Code.gs 전체가 GitHub 최신으로 교체됨)
5
배포 → 배포 관리 → 연필 → 새 버전 → 배포 → 웹앱 새로고침

전체 복사는 비상용입니다. 평소에는 패치 + syncCodeGsFromGithub만 쓰면 됩니다.

나중에 Code.gs가 또 바뀌면

  1. script.google.com → 실행 → syncCodeGsFromGithub
  2. 배포 → 새 버전

UI만 바뀐 커밋이면 동기화 없이 웹앱 새로고침만 하면 됩니다.
