휴대폰으로 GAS 배포

큰 index.html을 폰에 붙여넣을 필요 없습니다. 한 번만 Code.gs의 원격 UI 설정을 넣고, 이후에는 GitHub만 최신이면 웹앱 새로고침으로 반영됩니다.

지금 할 일 (최초 1회)

1
아래 패치 복사를 누릅니다.
2
Chrome/Safari에서 script.google.com → JMFC 스프레드시트에 연결된 프로젝트를 엽니다.
3
Code.gs에서 기존 function doGet … 블록을 지우고, 복사한 패치를 붙여넣습니다. (파일 맨 위 CONFIG에 이미 UI_HTML_URL이 있으면 패치의 CONFIG 부분은 건너뛰고 함수만 넣어도 됩니다.)
4
저장 → 상단 실행에서 useGithubUiPrBranch(머지 전) 또는 useGithubUiMain(머지 후) 실행. 권한 허용.
5
배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포. 웹앱 URL을 새로고침하면 최신 UI가 뜹니다.

전체 복사가 편하면 Code.gs만 통째로 교체하세요. index.html은 더 이상 붙여넣지 않아도 됩니다.

이후 업데이트 (매번)

  1. GitHub에 코드가 올라가면 끝 (이 채팅/PR 머지).
  2. 웹앱 링크만 새로고침. (캐시 때문에 안 바뀌면 시크릿/다른 브라우저)
  3. Code.gs 서버 로직이 바뀐 경우에만 위 배포 5번(새 버전)을 다시 합니다.
