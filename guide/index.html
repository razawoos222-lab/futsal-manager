JMFC 풋살매니저 목업 열기

마스터핀 없는 연습용 목업입니다. 드래프트 입장 때 세션 핀 4자리를 직접 정하세요.

전체 흐름

  1. 참석 → 감독 → 핀 → 드래프트 → 라인업
  2. 2팀 선택 → 경기 기록 → 경기 종료
  3. 결과 확인·공유 → 필요 시 기록 수정 → 저장
STEP 1

참석 조사

  1. 날짜를 확인합니다
  2. 2팀 / 3팀 / 4팀 구성을 고릅니다
  3. 참석 선수 칩을 탭해 선택합니다
  4. 「참석 완료 →」로 다음
STEP 2

감독 선택

  1. 팀 슬롯을 탭합니다
  2. 아래 선수 칩으로 감독을 지정합니다
  3. 모든 팀 감독을 채운 뒤 「다음 →」
  4. 감독은 이후 화면에서 C로 표시됩니다
STEP 3

세션 핀번호

  1. 첫 드래프트 입장 때 4자리 핀을 정합니다
  2. 드래프트 재입장·확정에 사용합니다
  3. 세션 리셋 전까지 유지됩니다
STEP 4

드래프트

  1. 스네이크 ON이면 픽 순서대로 팀이 바뀝니다
  2. 선수 카드를 탭해 배정합니다
  3. 랜덤 배정 / 드래그 이동도 가능합니다
  4. 전원 배정 후 「드래프트 완료」→ 핀 확인
STEP 5

라인업

  1. 팀별 명단을 확인합니다
  2. 감독(C)은 맨 앞입니다
  3. 「라인업 공유」로 이미지 저장·카톡 전송
STEP 6

경기 선택

  1. 붙일 2팀을 고릅니다
  2. 경기 시간(7~12분)을 설정합니다
  3. 「경기시작」으로 기록 화면 진입
STEP 7

경기 기록

  1. 「경기시작」으로 타이머를 켭니다
  2. 선수 이름 탭 → 득점/도움/수비/선방/자책
  3. ⇄ 로 교체·코트 아웃
  4. 「현재 경기 종료」로 다음 경기 준비
STEP 7-2

스탯 입력

  1. 원하는 스탯 버튼을 누릅니다
  2. 득점 후 도움 선수를 고를 수 있습니다
  3. 「스탯취소」로 마지막 기록을 되돌립니다
STEP 8

오늘의 결과

  1. MVP·최우수 감독·팀 순위를 확인합니다
  2. 「결과 공유」로 이미지 저장 후 카톡 전송
  3. 숫자 수정이 필요하면 「기록 수정」
  4. 끝나면 「기록 저장」
STEP 9

기록 수정

  1. 득점·도움·수비·선방 숫자를 고칩니다
  2. MP는 바로 다시 계산됩니다
  3. 감독(C)은 수정해도 유지됩니다
