사파리에서 배포하기

아이폰 사파리에서 script.google.com 이 404 나는 경우가 많습니다. Google이 모바일에서 편집기를 막아 두어서입니다.

404가 떴다면 링크가 잘못된 게 아니라, 아이폰에서는 Apps Script 편집기가 안 열리는 겁니다.
아래 순서대로 시도하고, 안 되면 PC/맥/아이패드에서 한 번만 패치를 넣으면 됩니다. 그 다음부터는 폰 웹앱으로 동기화 가능합니다.

아이폰에서 될 때까지 시도

1
JMFC 시트를 연 뒤, 사파리 aA → 데스크톱 웹 사이트 요청
JMFC 시트 열기 (데스크톱 모드)
2
상단 메뉴 확장 프로그램 → Apps Script 가 보이면 그걸 탭 (이게 제일 확실)
3
안 보이면 Chrome 앱 설치 후 같은 시트 URL을 열고, ⋮ → 데스크톱 사이트 → 확장 프로그램 → Apps Script
4
그래도 404면 아래 주소를 데스크톱 모드로 하나씩 시도
script.google.com/home script.google.com/home/start

편집기가 열렸을 때

1
짧은 패치 복사 → Code.gs 맨 아래 붙여넣기 · 저장 (기존 doGet이 있으면 삭제 후 패치만)
2
배포 → 배포 관리 → 연필 → 새 버전 → 배포
3
평소 웹앱 URL(시트가 아님) 끝에 ?jmfc=admin 붙여 열기 → 설정 → 동기화
현실적인 방법
아이폰에서 편집기가 끝까지 안 열리면, PC나 맥·아이패드에서 딱 1회 패치 + 새 버전만 해주세요.
그 다음부터 UI는 GitHub 자동, Code.gs는 폰에서 웹앱 ?jmfc=admin 으로 갱신합니다.

패치 / 링크

Apps Script API ON (동기화용) JMFC 시트 (참고 · 여기선 실행 불가) 이 도우미 다시 열기
