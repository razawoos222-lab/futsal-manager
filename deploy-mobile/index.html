사파리에서 배포하기

맞습니다. 시트 화면에서는 Apps Script를 실행할 수 없습니다. (아이폰 사파리·시트 앱 모두 동일)

지금 연 주소는 스프레드시트입니다.
스크립트는 script.google.com 으로 따로 열어야 합니다.

사파리에서 할 일

1
아래 버튼을 눌러 Apps Script 홈을 엽니다. (시트가 아님)
script.google.com 열기
2
사파리 주소창 옆 aA → 데스크톱 웹 사이트 요청 (편집기가 안 보이면 필수)
3
프로젝트 목록에서 JMFC 시트에 연결된 프로젝트를 탭합니다. 이름에 시트 제목이 들어 있는 경우가 많습니다.
4
짧은 패치 복사 후 Code.gs 맨 아래에 붙여넣고 저장(디스크 아이콘)
5
상단 배포 → 새 배포 또는 배포 관리 → 연필 → 새 버전
6
이미 쓰는 웹앱 URL 끝에 ?jmfc=admin 을 붙여 엽니다. (시트 URL이 아니라 웹앱 실행 URL)
실행 메뉴 대신
웹앱 주소 예시:
https://script.google.com/macros/s/×××/exec?jmfc=admin
거기서 설정 → Code.gs 동기화 버튼을 누르면 됩니다. 시트 편집 화면이 아닙니다.

패치 / 링크

Apps Script API ON (동기화용) JMFC 시트 (참고 · 여기선 실행 불가) 이 도우미 다시 열기
